# 🎬 Netflix Pakistan Landing Page Clone

A fully responsive **Netflix landing page clone** built using **HTML5** and **CSS3**.
This project recreates the look and feel of the official **Netflix Pakistan homepage** with a focus on clean UI, responsiveness, and modern frontend design.

---

# 🚀 Features

* 🎥 Hero section with background image and CTA
* 📺 Media feature sections with images & video overlays
* ❓ Interactive FAQ section with hover effects
* 📱 Fully responsive design
* 🌙 Netflix-inspired dark theme
* 🔗 Footer with useful links
* 🌐 Language selection dropdown

---

# 🛠️ Tech Stack

* **HTML5**
* **CSS3** *(No frameworks used)*
